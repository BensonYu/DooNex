# DooNex Web 工作台

需要 Node.js 24 与 pnpm 11。后端默认监听 `127.0.0.1:8741`，浏览器使用本地服务生成的访问令牌；模型密钥仅由服务端读取。

```bash
cd apps/web
pnpm install --frozen-lockfile
pnpm dev
```

开发界面位于 `http://127.0.0.1:5173`，`/api` 请求代理给本地后端。生产构建：

```bash
pnpm build
```

构建同时执行 TypeScript 检查，生成的 `dist/` 由产品 API 托管，不提交到仓库。前端每两秒按事件游标同步运行；浏览器刷新从服务端读取同一次运行，不创建新任务。访问令牌仅存于当前标签页会话，选中的运行 ID 存于本地浏览器存储。

当前范围为 M1 的单项目单 Agent 流程：项目校验、不可变输入、有限预算、暂停/取消/恢复核查、事件、diff、原始验证报告与工件下载。真实模型、隔离和证据有效性以服务端实际验收为准，页面不生成演示结果。
