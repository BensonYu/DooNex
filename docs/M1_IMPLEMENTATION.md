# M1 实施记录

更新：2026-11-06。状态：**M1 受控验收已完成。** 本文区分实现、实际证据与限制；PRD 仍是需求和发布门槛的唯一来源。

## 兼容性与实现选择

| 项目 | 当前事实与限制 |
| --- | --- |
| 主机 | macOS 27.0.1，Apple Silicon / arm64，16 GiB 内存；只据此主机验证，不推广为所有 Mac 支持 |
| Docker | Engine 29.8.2、Compose 5.5.0，OrbStack linux/arm64 引擎可用 |
| Python/SDK | 系统 Python 3.9.6 不用于应用；Python 3.12.16、OpenHands SDK 1.60.1 已安装并执行合同及真实任务 |
| 任务镜像 | 固定 `python:3.12.12-slim-bookworm@sha256:593bd06efe90efa80dc4eee3948be7c0fde4134606dd40d8dd8dbcade98e669c`，实测 arm64 |
| 数据库与界面 | FastAPI、PostgreSQL、独立 worker、React/TypeScript/Vite；依赖与数据库镜像均有锁定文件或内容摘要 |
| SDK 集成 | 可信进程运行 SDK 会话，工具回调才进入受限容器；不把模型配置交给任务代码，不重写 SDK Agent 循环 |
| 接口 | OpenAI 适配器支持显式 Chat/Responses；实际成功样例为 `gpt-6.1-sol` + Responses。Anthropic Chat 尚未真实调用验证 |

SDK 的 DockerWorkspace 默认平台与远端模型配置边界不直接满足本轮约束，因此保留既定架构，通过 SDK 自定义 shell 工具连接 ARM64 stateless 容器。SDK 内置费用限制不能代替每次请求前的产品预算预留。

## 已实施的 M1 流程

1. **项目与输入**：鉴权注册一个 Git 根目录，固定明确提交；通过 Git 对象导出独立工作副本，不触发 checkout hooks/filters，不带 `.git`，不混入原未提交内容。需求、模型配置、预算和验收命令作为不可变运行输入保存。
2. **执行与展示**：独立 worker 驱动单 Agent，只有受控 shell 与 finish 工具；PostgreSQL 保存运行、事件、动作意图与用量。Web 通过 HTTP 游标轮询展示同一运行，浏览器刷新不创建新任务。
3. **预算与停止**：模型请求前原子预留，关闭 SDK 隐式重试/回退；失败或未知结果保留预留。暂停、取消及超时阻止后续派发，核查在途容器；时长从首次启动累计，包含暂停。
4. **故障与续接**：PostgreSQL 全局会话锁和运行 owner 防止双 worker 与过期执行者写入；启动时核查残留容器、工作区和未决动作。SDK 未匹配动作阻止自动重放，用户确认后以保留代码的新会话续接。验证期恢复保留旧证据并创建新检查尝试。
5. **交付证据**：固定快照覆盖新增/删除、内容与文件权限；每条验收命令使用全新副本。保存 patch、快照归档、命令、退出码、日志、时间、镜像、内容清单及报告摘要；报告哈希绑定数据库，缺失、篡改或代码变化使验证失效。
6. **结果采纳**：可查看并下载补丁、快照、报告与检查日志；采纳预检检测目标提交漂移、未提交修改和冲突。实际整合由用户人工执行，不隐含推送或部署授权。

任务容器默认 `--network none`、只读根文件系统、非 root、去除 capabilities、禁止新增权限，并限制进程、内存、CPU 和工具时长；仅挂载授权代码副本和临时 `/tmp`。扫描不跟随软链接，并拒绝特殊文件、submodule、常见秘密文件名、过大或过多文件；常见缓存不进入快照。

## 计费与授权口径

- **按量计费**：必须配置有来源的输入/输出单价与费用上限；未知价格阻止启动。预留与已发生用量分别展示，未知响应不按零计费。
- **已授权包月**：费用、费用预留与费用上限为 `null`；仍执行调用/token/时长限制，不写成免费，也不推断其他套餐具有 API 权限。
- **真实验收总账**：`live_acceptance.py` 显式 opt-in，单次默认最多 4 次调用、50,000 token；整个 campaign 累计上限为 10 次调用、100,000 token。失败和未知用量保留记录，不能通过换模型、重启或删除账本清零。

## 已知限制与下一步

- 单项目、单有效 worker、单 Agent。没有多 Agent 编排、Skill 管理或 Arena；M2–M5 保持后续范围。
- 工作副本没有 `.git`，不支持任务内直接 Git 操作、submodule 或软链接项目；保守秘密名规则也会拒绝 `.env.example` 等合法模板。它不是完整源码秘密识别器。
- 固定任务镜像仅提供预装工具，无任务网络，不能在线下载依赖；其他语言和镜像需要独立审核与验证。文件数量/大小限制是扫描边界，不宣传为宿主磁盘的绝对硬配额。
- 当前模型输入 token 采用保守估算，实际用量依赖供应商响应；未知用量保留预留。预算不是供应商账单绝对封顶，包月也不是无限执行授权。
- SDK 使用少量私有覆盖来禁用宿主发现、额外工具和预算外元数据探测，固定版本升级须重跑合同测试。SDK 导入前清除四项 tracing 环境变量，关闭 `.env` 发现、远程价格表与遥测；已初始化的 tracing/回调进程拒绝复用，细节见 [架构](ARCHITECTURE.md)。
- 当前仅本机访问，Bearer 令牌和 Host/Origin 校验不等于已支持公网部署。凭据文件由本机权限保护，不承诺外部秘密管理服务。
- 只有 `gpt-6.1-sol` 的 Responses 路径取得本轮真实成功证据；Anthropic Chat 和其他模型/接口尚未真实验证。

下一步：继续使用 M1 收集实际任务反馈，优先记录项目适配、失败原因与恢复体验。SDK、镜像或应用代码发生变化时重新验证；不因样例通过提前扩展 M2–M5，也不把模型列表或单次成功写成全面兼容。
